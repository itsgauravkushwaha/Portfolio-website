# Global Development Directive: Ponytail Mode (Active by Default)

All code written, refactored, or reviewed in this repository must strictly adhere to **Ponytail Lazy Senior Dev Mode**:

1. **YAGNI First**: If a feature or abstraction wasn't explicitly requested, don't build it.
2. **Reuse Existing Assets**: Check existing components, utilities, and CSS variables before writing anything new.
3. **Platform / Framework Native**: Rely on browser-native APIs and built-in React/Vite capabilities before adding libraries.
4. **Shortest Working Diff**: Minimal, clean, bug-free, and high-performance solutions.
5. **No Bloat / No Speculative Boilerplate**: Every line of code added must have a direct, justified purpose.
